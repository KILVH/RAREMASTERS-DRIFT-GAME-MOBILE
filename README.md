# RAREMASTERS DRIFT GAME — MOBILE

Оптимизация производительности 2 октября 2026. Подробности: [PERFORMANCE_REPORT.md](PERFORMANCE_REPORT.md).

Финальные правки: [FINAL_REPORT.md](FINAL_REPORT.md).

Мобильные изменения и ограничения проверки: [MOBILE_REPORT.md](MOBILE_REPORT.md).

Обновление 1 октября 2026. Это существующая игра с правками из NEW TEST, без переписывания проекта.

Полный список изменений, исправленных ошибок, оптимизаций и результатов проверки: [NEW_TEST_REPORT.md](NEW_TEST_REPORT.md).

Начни с Город → LOUD SOUND (покупка STANDARD 10000 / PRO 50000), затем AR DRIVE (установка 10000). Только после этого доступна музыка. Апгрейд STANDARD → PRO — 40000, установка сохраняется.

Четыре заставки соответствуют одежде Хоумбоя. Менять одежду можно в Dolbogram. Вызовы Борща и Хаслера появляются с 5000 подписчиков. Гоча и Царь могут пригласить после соревнования на 80+ баллов.

Управление: стрелки или WASD, пробел — ручник, ESC — пауза. На телефоне используются нижние кнопки; рекомендуется альбомная ориентация. Ручник начинает занос, газ поддерживает его. В настройках есть режим 30/60 FPS и отдельные переключатели звуков.

Прогресс хранится на устройстве в прежнем сохранении. Не очищай данные сайта для обновления. Экспорт — в настройках. На другом адресе сайта браузер использует отдельное хранилище.

Проект статический. Для локального запуска есть START_GAME.cmd в рабочем проекте. Пакет RAREMASTERS-DRIFT-FINAL-GITHUB предназначен для размещения содержимого в корне репозитория GitHub Pages; инструкции в README_GITHUB.txt. npm-сборка не требуется.

Проверки Node подтверждают логику и движение на реальных масках. Реальная мобильная отрисовка, FPS, звук и ощущения от управления требуют ручной проверки; полный браузерный приемочный тест не заявляется пройденным.
